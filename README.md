# CMS Test Automation

Selenium WebDriver test automation for the Capacity Monitoring System.

## Stack
Java, Maven, TestNG, Selenium 4

## Setup
1. Clone the repo
2. Copy `config.properties.example` to `config.properties` and fill in credentials
3. Run: `mvn test`

## Structure
- `src/main/java/com/eventum/cms/pages` — page objects
- `src/test/java/com/eventum/cms/tests` — test classes
